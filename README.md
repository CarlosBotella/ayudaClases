# Viaje Lector

PWA para practicar lectoescritura en español con una alumna de 7 años: minijuegos con texto
decodificable por mundos y un panel de análisis para el tutor.

- **Web:** https://carlosbotella.github.io/ayudaClases/
- **Stack:** Vite + React + TypeScript + Tailwind CSS + vite-plugin-pwa · Firebase (plan Spark) · GitHub Pages.
- **Publicación:** cada push a `main` ejecuta `.github/workflows/deploy.yml`
  (instalar → tests → compilar → publicar).

## Privacidad

Solo se guarda el nombre de pila de la alumna. Sin audio, micrófono, cámara ni analítica de terceros.
Datos en Firestore, región europea.
